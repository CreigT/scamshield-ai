# Contributing

Thank you for contributing to ScamShield AI.

1. Keep each change scoped to a clear objective.
2. Never include secrets, customer information, or proprietary data.
3. Add or update tests for behavioral changes.
4. Update documentation when behavior or configuration changes.
5. Preserve ScamShield's no-link-navigation and no-automatic-payment/reply boundaries.
6. Do not weaken privacy or security controls without documenting the reason and risk.

Pull requests should explain what changed, why, how it was tested, security implications, and any new environment variables, permissions, or external services.

Contributions are made under this repository's license.
